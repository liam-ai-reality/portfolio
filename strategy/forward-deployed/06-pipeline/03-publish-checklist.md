# Publish checklist

Run before every upload goes public. No exceptions for the good ones.

## Content

- [ ] NDA gate: all five questions re-checked **against the final cut**, not the script.
      A sentence can be improvised into a breach during the take.
- [ ] Every number stated is either mine, public, or synthetic — and correct
- [ ] Every claim maps to a receipt ID; opinions labelled as opinions
- [ ] Regulated episodes: "engineer, not a lawyer" boundary stated on camera
- [ ] Regulated episodes: date visible on screen (guidance moves)
- [ ] Demo Tax: original credited, fix shipped, not punching down
- [ ] No client system, dashboard, data or code visible in any frame — including
      browser tabs, terminal history, notification banners, and file trees

## Packaging

- [ ] Title front-loads the searchable term, under ~50 chars before truncation
- [ ] Title does not overstate the finding
- [ ] Thumbnail legible at 210px; one number or three words; no stock imagery
- [ ] Description: one-paragraph summary, timestamps, bridge asset link with UTM,
      links to the two adjacent funnel-tier videos
- [ ] Playlist assigned (one per series — the funnel has to be visible)
- [ ] End screen points to the next tier down the funnel, not to a random video
- [ ] Pinned comment: the bridge asset, stated plainly

## Distribution

- [ ] 3 Shorts cut from the marked points, scheduled across the fortnight
- [ ] LinkedIn post — different framing, not a link dump. This is where the network is.
- [ ] Bridge asset live on liam.dev, capture tested end to end

## Logging

- [ ] Actual hours recorded in the episode file
- [ ] UTM registered in `08-measure/`
- [ ] Publish date logged

## The final check

Watch the first 15 seconds with the sound off, then with the sound on and the picture
off. If either one fails to make a stranger want the next 15 seconds, fix the open
before publishing. Everything after the hook is wasted if the hook doesn't land.
