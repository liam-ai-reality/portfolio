## Notes

**The hook is the whole game.** Fifteen seconds, no greeting, no "in today's video".
Open on the failure, the number, or the claim. Write it verbatim and read it back
before shooting — if it doesn't work on the page it won't work on camera.

**"The one sentence" is the real test.** If you can't write what the viewer repeats
to a colleague, the episode has no point yet. Don't shoot it.

**Fill "actual hours" honestly.** It feeds the season gate, and the gate only works
if the number is true.
