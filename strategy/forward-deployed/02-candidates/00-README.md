# Candidate schema

Every candidate uses these headings, in this order, unchanged. Comparability is the
entire point — a candidate that "doesn't fit the schema" is a candidate that hasn't
been thought through.

```markdown
# C<n> — <name>

## Premise
One paragraph. What the channel or series is, stated so a stranger could commission it.

## Core loop
The repeatable thing that happens every episode. If there isn't one, this is a topic,
not a format.

## Who watches
Specific. Job title, what they were doing five minutes before, what they typed.

## Can they buy?
Direct answer to the primary goal. Budget authority: yes / sometimes / no.

## Receipts spent
Which IDs from 00-context/02-receipts-inventory.md this depends on.

## NDA route
A, B, C (from 00-context/05-nda-boundaries.md) or "fails gate".

## Production cost
Hours per episode, honestly, including build time.

## Discovery mechanism
How a stranger arrives. Search / borrowed demand / recommendation / referral.

## Bridge asset
What the viewer is offered to move from watching to a conversation.

## Kill condition
What observation would prove this candidate wrong. If nothing could, it's unfalsifiable
and should not be scored.
```
